# 🛒 Lista de Compras

Projeto de uma lista de compras desenvolvido durante os estudos com a **[Rocketseat](https://www.rocketseat.com.br/)**, com o objetivo de praticar conceitos de desenvolvimento web utilizando HTML, CSS e JavaScript.

## ✨ Funcionalidades

- ➕ Adicionar produtos à lista de compras.
- ☑️ Marcar produtos como comprados.
- 🗑️ Remover produtos da lista.
- 🔔 Exibir notificações ao remover itens.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🌐 Demonstração

[Acessar o projeto online](https://adison-gs.github.io/Lista-de-compras/)

## 📚 Aprendizados

Este projeto contribuiu para a prática de conceitos fundamentais do desenvolvimento front-end, incluindo manipulação do DOM, eventos em JavaScript e estilização de interfaces com CSS.
